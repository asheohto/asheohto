```text

│  ✨ Name:     Marya (asheohto / ashe)                  │
│  📍 Location: Malaysia 🇲🇾                              │
│  🎓 Status:   Student & Systems Tinkerer               │
│  ⚡ Focus:    Low-overhead native Windows utilities    │
│  ☕ Support:  https://ko-fi.com/omoretti               │
╰────────────────────────────────────────────────────────╯
```

- 🦀 **Systems & Desktop Engineering**: Building high-performance native desktop tools in **Rust** and **C# (.NET 9 Native AOT)**.
- 🪟 **Hardware & Windows Internals**: Reverse engineering Embedded Controller (EC) registers, WMI BIOS calls, and low-level audio routing.
- 🍃 **Anti-Bloat Philosophy**: Every utility starts in milliseconds, uses zero background memory, and cleanly shuts down or idles silently.
- 🎧 **Audiophile & Music Enthusiast**: Building synchronised lyric overlays and decluttering noisy virtual sound devices.

hey! i'm marya. i like writing tiny, native desktop tools for windows that do one job well and don't hog background ram. mostly interested in systems programming, reverse engineering embedded controllers, audio routing, and low-overhead ui.

---

### 📦 projects

- ❄️ **[Cremecore](https://github.com/asheohto/cremecore)** — lightweight, open-source fan controller for hp omen/victus laptops. written in rust with a freya gui and a background hardware daemon for direct ec/wmi control.
- 🎧 **[Cremey](https://github.com/asheohto/cremey)** — turns off steelseries sonar's spam of virtual audio devices on boot, then exits cleanly in seconds. compiled with .net 9 native aot (0 mb idle ram).
- 🎵 **[Lyricreme](https://github.com/asheohto/lyricreme)** — transparent, click-through desktop lyric overlay for windows with synchronized scrolling via pear desktop & tuna obs.
- 🍃 **[Fanly](https://github.com/asheohto/Fanly)** / **[CremeFan](https://github.com/asheohto/CremeFan)** — direct ec register access and wmi bios calls for thermal management without vendor bloatware.
- ✨ **[asheohto](https://github.com/asheohto/asheohto)** — this repo right here (my profile & config notes).
